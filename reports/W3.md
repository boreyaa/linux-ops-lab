## 卡点

1. 按教程 count=3000 写 3G，df 只到 34%，故障没造出来。原因是该机根分区可用 27G，固定块数不适用。改法是用 df 的 Avail 动态算块数，写成 count=$((avail+128))。
2. 直接跑 python3 -m http.server 80 报 OSError: [Errno 98] Address already in use。原因是 nginx 已在运行并占用 80，与教程"nginx 处于停止状态"的前提相反。改法是先 systemctl stop nginx，用 ss 确认 80 为空，再让 python 占位。
3. range(200) 累计约 2G，机器 3.8G 内存装得下，没有触发 OOM，dmesg 也查不到记录。改成 range(1000) 后才出现 Killed 与 dmesg 日志。
