## 四、与文档不一致的三处

1. **仓库用 GitHub 未用 Gitee**。实测服务器访问 github.com 超时（HTTP=000，10 秒无响应），访问 gitee.com 正常（200，0.7 秒）。因此服务器无法 clone GitHub，改走文档备用方案 rsync。虚拟机可正常 push GitHub，故代码仍进仓库，只是服务器不 clone。

2. **项目放 ~/asminsight 而非 /opt/asminsight**。服务器 sudo 需密码，当前会话无法提权，/opt 归 root 不可写。

3. **nmap 未预装**。D1 装机清单为 curl git vim htop，不含 nmap，而 `collectors/ports.py` 硬依赖 nmap，缺失时报「失败: nmap 未安装」。处理方式：`apt-get download nmap nmap-common libssh2-1t64 liblinear4 liblua5.4-0 libpcap0.8t64 libblas3 libgfortran5 libquadmath0`，用 `dpkg-deb -x` 解包到 `~/opt/nmap`，包装脚本 `~/.local/bin/nmap` 设 LD_LIBRARY_PATH 与 --datadir。**建议改用 `sudo apt install -y nmap` 正式安装**，当前方案在 cron 下需显式指定 PATH。
